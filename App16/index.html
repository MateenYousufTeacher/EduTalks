How the System Works
Automatic 8-step response pipeline
1
Fall Detected
Sensors detect sudden downward acceleration & impact — consistent with a fall event.
2
Inactivity Check
System monitors for continued movement. No movement = possible inability to get up.
3
10-Second Warning
Elder is given 10 seconds to confirm they are safe. False alarm cancellation available.
4
Auto SOS Trigger
If no response — SOS activates automatically. System acts when the user cannot.
5
Location Captured
Exact GPS coordinates sent with alert so helpers can navigate directly to the elder.
6
Alert Broadcast
Caregiver, family, and nearby volunteers all receive emergency notification instantly.
7
Help Nearby Triggered
Help Nearby module activates automatically — nearby community members mobilize.
8
Elder Assisted
First responder arrives. Confirmation sent back. System returns to normal monitoring.
