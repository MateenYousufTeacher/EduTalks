About this lab

Virtual Simulations is an offline-first Environmental Science laboratory built around ten independent experiments covering soil, ecology, population, water, chemistry, sound, hazards, agriculture and impact assessment. Every model runs on real calculations — not scripted animations — so results change meaningfully with the variables you choose.

Designed for Classes VI–XII, usable on any device, and fully functional without an internet connection once installed.
